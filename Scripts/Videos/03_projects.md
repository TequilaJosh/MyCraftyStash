# 03 — Projects

**Target runtime:** ~3:00
**Goal:** Show that a Project in MCS is more than a photo — it's a living record of how a card was built, what went into it, and every time you remake it.

---

| VISUAL | VOICEOVER |
|---|---|
| **[0:00–0:10]** B-roll: finished card sitting on a desk; pull-back to reveal the same card photographed on a phone, the photo never opened again. | "You finish a beautiful card. You take a picture. And then… that's where the record ends." |
| **[0:10–0:25]** Cut to MCS Projects view. Cards in a wrap grid: photo, name, description, "N items used" badge. | "Not in My Crafty Stash. The Projects view turns every finished card into a full build record — photo, supplies used, the steps you took, and every time you've made it since." |
| **[0:25–0:45]** Type in the search box. Open the Type dropdown → pick a type. Subtype checkboxes appear. Open **Specific Item** dropdown — projects filter to just the ones using that item. | "Search by project name, filter by type, or — and this one's powerful — filter by **specific item**. Want to see every card you've ever made with that one floral stamp set? One click." |
| **[0:45–1:00]** Click a project card → Project Detail view opens. Large image, name, description, date created, "Items Used" sidebar. | "Open any project and you see the full picture. The finished card, the date you made it, and on the right — every supply that went into it, linked back to your inventory." |
| **[1:00–1:25]** Click **I Made One!** → small dialog. Add a note. Tick "Subtract materials from inventory." Confirm. The Creation History list grows by one row. | "When you make the card again — and you will — hit **I Made One!** Add a note if you want. Tick the box, and the supplies come straight out of your stock counts. No spreadsheet, no double-entry." |
| **[1:25–1:50]** Scroll to **How It Was Made** card. Show the list of build steps: Cardbase, Cardstock, Focal Image, Sentiment, etc. Click **Edit Card Build**. | "Below the photo is the **How It Was Made** card — your actual build recipe. Step by step, supply by supply. If you didn't build one when you saved the project, the **Build Card** button gets you started." |
| **[1:50–2:05]** Close the project. Click **+ Add Project** in the sidebar. New project form opens. | "Creating a new project is just as easy. Sidebar → Add Project." |
| **[2:05–2:25]** Drag an image into the dropzone on the left. Type a name. Click **Card Builder** button. | "Drop in a photo, give it a name, and click **Card Builder** to walk through what went into it. That opens the Card Build Wizard — the subject of the next video." |
| **[2:25–2:45]** Back to the Projects grid. Click **Import shared…** → file picker → pick a `.mcsproject` file. The new project appears with a "Shared" badge. | "Projects are also shareable. Export one to a `.mcsproject` file and a friend can import it — supplies, steps, photo and all — with a single click." |
| **[2:45–3:00]** End card: "Next up — **the Card Build Wizard**." | "Every project's build is created in the wizard. Let's go there next." |

## Shot list reminders

- Use a project with at least 3 creation-history rows so "I Made One!" feels meaningful.
- Pre-write a project description with a line break so the card layout looks polished.
- The Shared badge is a nice trust signal — make sure the demo imports one.

# Tags, Titles & Descriptions

SEO scaffolding for the seven videos in this folder. Each entry gives you:

- **Title options**: A/B them; pick by which thumbnail you land on.
- **Description**: first 2 lines show in search; the rest is for the YouTube algorithm to classify the video.
- **Tags**: paste into the tag field, comma-separated.
- **Hashtags**: for Reels / Shorts / TikTok cross-posts; YouTube also picks up the first 3 from the description.

The lead tag in every set is `my crafty stash` so anyone searching the app name finds your channel first.

## Tag-strategy notes

### What weighs what
- **Title** does ~70% of the discoverability work, the search query has to land in it.
- **Thumbnail + first 2 lines of description** drive click-through.
- **Tags** help YouTube *classify* the video (what audience to serve it to), not rank it. Don't agonize over them.
- **First 15 seconds of audio/video** drive retention, which then drives recommendation. The script files in this folder are tuned for this.

### Don'ts
- Don't paste trending tags that don't match the video, YouTube and Meta both penalize this now, and it tanks recommendation quality even when it doesn't get you suspended.
- Don't repeat the same word ten times in different combinations, YouTube collapses near-duplicates.
- Don't exceed ~500 chars total in the tag field; YouTube ignores the overflow.

### Per-platform notes
- **YouTube long-form (the tutorials):** title + description + tags as written above.
- **YouTube Shorts / Reels / TikTok:** use 5–8 hashtags inside the caption itself (not the description block); the first 3 carry the most weight.
- **Instagram:** hashtags in the first comment, not the caption, keeps the caption readable.
- **Pinterest:** treat each video as a Pin, title + description = your description block; tags don't exist, but the keywords in the description do all the work.

### Iteration
Check **YouTube Studio → Analytics → Reach → Traffic source: YouTube search** after each video has been up for ~2 weeks. Any tag/keyword pulling impressions is worth doubling down on; anything at zero can be swapped. Treat the first month's tags as a draft.

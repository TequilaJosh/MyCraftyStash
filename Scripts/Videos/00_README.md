# My Crafty Stash, Video Scripts

Tutorial scripts (2–4 min each) for the six core features of My Crafty Stash, plus a 45–60 second feature-montage advertisement.

Each script uses a two-column format:

| **VISUAL** (what's on screen) | **VOICEOVER / AUDIO** (what's said) |

Timecodes are approximate: use them as pacing guides, not hard cuts.

## Demo data

Before recording, seed the database with the synthetic dataset in [demo-data/](demo-data/). It populates inventory, projects, card builds, wishlists, and calendar events so every shot in every script has on-screen data to point at.

See [demo-data/README.md](demo-data/README.md) for what gets seeded and how to apply or wipe it.

## Production notes

- **Tone**: warm, conversational, "fellow crafter", not corporate.
- **Pacing**: the voiceover is the spine. Cut B-roll to match speech, not the other way around.
- **Cursor**: enlarge and slow it down in screen recordings: viewers need to track where you click.
- **Text callouts**: lean on lower-thirds for feature names ("Card Build Wizard", "Color Match") so viewers can mute and still follow.
- **Music**: light acoustic / lo-fi bed at -20 dB under VO. Lift to -12 dB during transitions.

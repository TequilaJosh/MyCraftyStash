# YouTube Descriptions

Polished, copy-paste-ready descriptions for each video. Drop these straight into the YouTube description field at upload time.

## Conventions used

- **First 2 lines** appear in search results and above the "Show more" fold. They're written to hook and to land searchable keywords.
- **Chapter timestamps** are suggested from script pacing, **edit them to match your actual cut times** before publishing. YouTube needs `00:00 Title` format with the first chapter at exactly `00:00`.
- **`[…]` placeholders** are things you fill in once: download URL, playlist URL, etc.
- **Hashtags** at the very end, YouTube auto-promotes the first three to the top of the description bar.
